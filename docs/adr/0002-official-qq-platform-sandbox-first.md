# 接入 QQ 官方机器人平台，且全程在沙箱环境开发

QQ 机器人有两条接入路线：官方开放平台，或 OneBot 生态的非官方协议实现（NapCat 等）。非官方路线没有回复窗口限制、没有 URL 白名单、能发任意文件，但违反腾讯服务条款、账号有封禁风险、且腾讯每次调整协议都可能失效。本项目的交付场景包含演示，一个可能因封号而演示失败的方案风险不可接受，因此选官方平台。官方平台的回复窗口约束（群聊 5 分钟、单聊 60 分钟）有对应的工程解法，封号没有。

配套决定：**开发与演示全程在沙箱环境完成。** 官方平台的沙箱环境（`sandbox.api.sgroup.qq.com`）不受 IP 白名单限制，沙箱群成员上限 20 人，而本项目的目标使用规模正好在此之内。这意味着不需要提审上线、不需要公网固定 IP、不需要 ICP 备案域名，WebSocket 模式下可以纯本地开发。

正式上线（公网 HTTPS webhook、端口限 80/443/8080/8443、IP 白名单、自测报告、提审、手动上线、URL 白名单需 ICP 备案）是一套独立的行政流程，不阻塞任何技术验证，放在最后处理。为此所有对外链接必须经过一个统一的出链函数，届时只换实现。

顺带记录一个已排除的选项：`Mrs4s/go-cqhttp` 已停止维护（最后发布 2023-10），不作为候选。官方 Go SDK `tencent-connect/botgo` 停更在 2024-12（v0.2.1），不覆盖 2026 年新增接口，仅用于 access token 刷新与 webhook 签名校验，业务接口自行实现 HTTP 客户端。
