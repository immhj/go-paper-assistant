# 研究生工具集平台

一个面向研究生的免费工具集平台：访客无需登录即可有限使用，注册账号后获得可持续的身份与数据归属。第一个接入的工具是**论文助手**（术语见根 [`CONTEXT.md`](../../../CONTEXT.md)）。平台负责身份、鉴权和导航，不关心任何单个工具的内部领域。

## Language

### 身份

**访客**:
没有注册或登录账号、通过 Web 聊天通道使用平台的人。访客可以创建和使用研究项目；普通聊天、论文检索和速览没有产品次数额度，并在一个访客凭证周期内获得一次精读资格，项目能力不另设产品次数额度。访客不是账号，也不是论文助手里的 QQ「用户」。平台对访客的识别强度低于账号，不能承诺永久身份。访客可在之后注册或登录账号。
_Avoid_: 匿名用户、游客用户、用户

**访客凭证**:
平台为未登录浏览器签发的临时身份，生命周期为三十天。它让访客在刷新或重新打开页面后恢复历史与精读资格状态，但不能提供账号级别的永久身份保证。凭证过期后，对应的未注册访客数据可被清理。
_Avoid_: 访客账号、匿名 JWT、设备指纹

**访客精读资格**:
每个访客凭证周期内可消费的一次论文精读机会。执行前先原子预留；系统失败且没有产生可恢复的有效精读结果时退还，结果成功保存后正式消费，即使浏览器随后断线也不退还。它是唯一施加在访客功能上的产品次数额度；普通聊天、论文检索和速览没有产品次数额度。它不是 QQ 被动回复额度，也不是安全限流。
_Avoid_: 免费会员、请求限流

**账号**:
平台的持久登录身份，由邮箱验证后注册产生。账号可无限使用论文精读，但仍受每账号同时一次、每分钟最多发起两次精读的安全限制，以及其他防滥用速率限制、全局成本熔断与人工急停；“无限”表示没有产品次数额度，不表示允许自动化轰炸服务。账号是已登录状态下平台数据归属的主体：论文助手的研究项目直接归属账号，Web 会话再归属研究项目；后续各工具的账号数据也挂在账号上。账号项目可跨设备恢复，但用户下载到设备的 PDF 不由平台同步。账号与论文助手里的「用户」是两个对象——「用户」是匿名的 QQ 标识，账号是有凭证的登录身份，二者可以指向同一个自然人，也可以毫无关系。
_Avoid_: 用户（这个词在论文助手里已被 QQ 用户占用）、会员

**邮箱**:
账号的登录凭证与验证目标，全局唯一。注册人必须证明自己能接收该邮箱的验证码，验证成功后才能创建账号；邮箱也是找回密码的锚点。
_Avoid_: 账户名、登录名

**待验证注册**:
注册人已经提交邮箱、密码和昵称并请求验证码，但尚未通过邮箱验证的临时状态。待验证注册不是账号，不拥有账号数据；只有验证码验证成功后才创建账号。
_Avoid_: 临时账号、未激活账号

**邮箱验证码**:
发送到注册邮箱、用于证明注册人能够接收该邮箱邮件的一次性六位数字凭证。验证码由平台随机生成，通过平台专用的个人 QQ 邮箱发件地址发送。验证码十分钟过期、最多验证五次、同一邮箱六十秒内不可重发；新验证码发出后旧验证码立即失效。注册与密码重置的验证码用途严格隔离，不能交叉使用。验证码只证明邮箱可接收，不代表付费资格或邀请关系。
_Avoid_: 邀请码、激活码、注册码

**访客升级**:
访客完成邮箱验证并注册账号后，将当前访客凭证在三十天内保存的研究项目连同其中的会话、项目论文和精读结果转移给新账号，并使原访客凭证失效。各项目保持独立，不因名称相同而合并；各会话的消息和论文序号也不拼接。升级改变身份与数据归属，不改变产品免费的性质。
_Avoid_: 付费转化、开通会员、绑定账号

**访客记录导入**:
已有账号登录时，将当前浏览器的访客项目转入该账号的可选动作。平台必须先询问，只有账号明确确认才导入；拒绝导入时，访客项目保留至原三十天期限。导入时同名项目仍保持独立，不合并项目、会话、消息或论文序号；导入完成后恢复访客此前的当前项目和其中的当前会话。
_Avoid_: 自动合并、消息拼接

**密码重置**:
账号持有人通过注册邮箱接收专用验证码并设置新密码的自助恢复流程。重置验证码与注册验证码用途隔离，不能互换。重置成功后账号的鉴权版本递增，所有设备上的旧 JWT 立即失效，必须重新登录。
_Avoid_: 找回原密码、管理员改密

**访客数据清除**:
访客主动删除当前凭证关联的研究项目、会话、消息、项目论文关系、精读结果入口和精读资格状态，并使当前访客凭证失效的隐私操作。清除不删除跨主体共享的论文或全文缓存。页面必须说明访客记录最多保存三十天并提供清除入口；清除后平台可签发新访客凭证，但短期 IP 安全限制不会因此解除。
_Avoid_: 退出登录、清理浏览器缓存

**账号注销**:
永久删除账号及其数据的流程。首版不提供自助账号注销，账号持有人需要联系管理员处理；这与管理员仅将账号设为停用不同。
_Avoid_: 退出登录、停用账号

**安全限流**:
为防止模型成本滥用、邮件轰炸和服务过载而设置的请求频率、时间窗与并发边界。每个访客或账号同时最多执行一个模型任务；普通聊天每分钟最多十次，检索或速览每分钟最多三次，账号精读每分钟最多两次；每个 IP 每分钟最多三十个 API 请求。登录失败连续五次后逐步延迟，并在十五分钟后恢复。安全限流适用于访客和账号，与产品是否免费、功能是否有次数额度无关。
_Avoid_: 产品额度、精读次数、会员限制

**全局成本熔断**:
平台对全部模型与论文处理操作设置的最终成本保险丝。默认小时预算为二美元、每日预算为十美元，任一达到即暂停新的昂贵操作，但不影响注册、登录、历史查看和管理后台；预算可通过运行配置调整，区别于管理员主动开启的全局急停。
_Avoid_: 账号额度、付费墙、全局急停

**昵称**:
账号自选的展示名，界面上显示，可改、不唯一，纯装饰。改昵称不影响任何归属关系。
_Avoid_: 用户名、名字

**用户名**:
系统生成的、唯一且永久稳定的内部标识，用户不可见、不可改。它是把账号和它拥有的数据绑在一起的键，写进 JWT，作为各工具数据的归属键。之所以和邮箱、昵称分开：登录凭证会换、展示名会改，而归属键一旦变动就会让用户的历史数据成为孤儿。
_Avoid_: 昵称、账号 ID、登录名

### 鉴权

**JWT**:
面向平台账号的登录令牌，携带用户名和账号鉴权版本，登录后由前端在后续请求里带上。签名、有效期、账号状态和鉴权版本都有效时才代表账号；重置密码会递增鉴权版本并立即使旧 JWT 失效。访客不持有账号 JWT；管理后台使用另一套鉴权，两者不共用。完全没有 JWT 的聊天请求按访客处理，携带无效 JWT 的请求返回身份错误，不静默降级成访客。
_Avoid_: 访客凭证、cookie 会话

**管理后台鉴权**:
管理后台沿用既有的 HTTP Basic Auth（单管理员、账号来自环境变量），与平台账号的 JWT 完全分离。管理员不是账号，账号也不能进管理后台。
_Avoid_: 管理员账号（避免与「账号」混淆）

### 通道

**Web 聊天通道**:
论文助手在网页上的入口：HTTP + SSE 逐帧 JSON 流式，复用论文助手既有的确定性编排。它同时接纳访客和账号；两者使用不同强度的身份与使用限制。Web 聊天通道与 QQ 单聊通道并列，不受 QQ 被动回复四次上限约束。详见 ADR 0013。
_Avoid_: 网页版、H5

**QQ 绑定**:
把一个平台账号关联到一个 `qq_openid` 的可选动作，关联后同一个人两条通道的会话历史可以合并查看。v1 不强制绑定，绑定列可空。
_Avoid_: 关联、authorize

### 工具

**工具**:
平台上一个独立的功能单元，访客或账号从工具导航进入。论文助手是第一个工具。平台对工具只做身份、导航和通用访问控制，不侵入其内部领域。
_Avoid_: 模块、功能、应用

**工具导航**:
平台界面上在工具之间切换的入口。新增一个工具意味着往导航里加一个条目，而不是改造平台本身。
_Avoid_: 菜单、tab

## 管理后台信息架构

管理后台从「论文助手管理后台」升级为**研究生工具管理后台**。原有的三个导航项（概览 / 用户与会话 / 运行设置）是论文助手这一个工具的东西，现在整体**降一级**，收到「论文助手」这个一级项之下；平台级的账号管理单列一级项。

一级标题（顶层导航，按工具或平台域划分）与二级标题（某个一级项内部的分页）：

- **平台**（一级）
  - 账号（二级）—— 账号列表、邮箱验证状态、启用/禁用
- **论文助手**（一级）
  - 概览（二级）—— 原「概览」
  - 用户与会话（二级）—— 原「用户与会话」
  - 运行设置（二级）—— 原「运行设置」（含全局急停）

> 「一级」按**工具/平台域**切分，「二级」是该域内部的页面。判断一个新页面放哪：它是描述整个平台的，进「平台」一级；只描述某个工具的，进那个工具的一级之下。这条规则保证后续接入第 N 个工具时，导航结构不需要重新设计——只是多一个一级项和它的若干二级项。
